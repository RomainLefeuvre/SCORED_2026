## How to generate a new graph

## simple dataset generation

You need to have the jar swh-graph-3.0.1.jar in your directory `/home/<USER>/.local/lib/python3.10/site-packages/java/target`

Command

```
cp swh-graph-3.0.1.jar /home/<USER>/.local/lib/python3.10/site-packages/java/target/
```

You can add a new graph in the folder `gitwebgraphs` and add it in the file `all_Dataset.py`

To generate it afterward, use the command:

```sh
python3 generate_dataset.py --compress
```

### Python regression tests

One of the tests involves checking for non-regression by applying the algorythm again on the same data expecting a same output.
The dataset used is the [2021-03-23-popular-3k-python](https://docs.softwareheritage.org/devel/swh-dataset/graph/dataset.html#popular-3k-python) and must be located at src/test/resources/dataset/2021-03-23-popular-3k-python in order for the test to work.(see the [documentation](https://docs.softwareheritage.org/devel/swh-graph/quickstart.html#retrieving-a-compressed-graph) for information to retrieve the graph)
